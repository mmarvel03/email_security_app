# Email Spam and Phishing Detector

A Flask-based web application that analyzes email content and URLs to classify messages as SAFE, SPAM, or PHISHING. The system uses Machine Learning, TF-IDF text processing, and heuristic security rules to provide a risk score and explain each decision.

## Features

- Email classification: SAFE, SPAM, PHISHING
- Machine Learning model for spam detection
- TF-IDF text vectorization
- Heuristic phishing detection rules
- URL and suspicious keyword analysis
- Risk score calculation
- Analysis history saved in SQLite
- Simple and intuitive web interface

## Technologies Used

- Python
- Flask
- scikit-learn
- TF-IDF Vectorizer
- SQLite
- HTML / CSS
- Pickle
